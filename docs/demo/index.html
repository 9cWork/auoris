Benchmark

Every model gets the same questions, each with one right answer that Auoris checks itself (no model grades another). The score is the share answered correctly. Questions are sent with no chat history or tools; cloud models send them to that provider and cost a little, local models run one after another.

Chat with a folder

This is keyword search, not embeddings. Auoris indexes the text files in the folder you choose (skipping binaries, very large files, secret-looking files such as .env, and build/dependency folders). For each message you send in this chat it finds the few best-matching passages and adds them to what the model sees, labelled with their file paths. It only reads inside that folder and never runs anything. With a cloud model, those passages are sent to that provider.

Export chats

You choose where the file is saved. Incognito chats are only included if one is the chat you have open. Messages don't store timestamps, so only the chat's last-updated time is shown.

Import chats

Bring your history from other AI apps in as normal saved chats (plain text, nothing is run). Download your export first, then choose the file here. Files are read on this computer only.
ChatGPT: Settings → Data controls → Export data. Claude: Settings → Privacy → Export data. Both email you a link to a ZIP; pick the ZIP (or its conversations.json). You can also pick a generic JSON file or an Auoris Markdown export.
