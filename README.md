# 🌙 Tricoom

**Your local AI workshop for Windows.** Chat with AI models that run entirely on your own PC, or switch to Code mode and let the AI read your files, write code, run commands and build projects.

## Install

1. Download **`Tricoom-Setup.exe`** from the [latest release](../../releases/latest).
2. Run it. Setup installs everything Tricoom needs (Ollama, and optionally the AI model).
3. Windows may show "Windows protected your PC" because the installer isn't code-signed. Click **More info → Run anyway**.

Installed copies update themselves automatically when a new release is published here.

## Features

- 💬 **Chat** and ⌘ **Code** modes, with saved history, incognito chats and slash commands
- 🧭 **Explore** — find and download GGUF models from Hugging Face, with GPU-fit estimates
- ⏱ **Routines** — prompts that run on a schedule
- 🔒 Permission modes, including an "AI decides" mode with built-in safety rules
- 🎨 Profiles with custom avatars, banners and effects, 9 languages, accent colors
- 📊 Token usage and GPU memory stats

Everything runs locally through [Ollama](https://ollama.com). Nothing is sent to the cloud.
