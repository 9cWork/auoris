# 🌙 Auoris

**Your local AI workshop for Windows.** Chat with AI models that run entirely on your own PC, or switch to Code mode and let the AI read your files, write code, run commands and build projects. Sign in for Servers, DMs, group chats, AI Projects, game hosting and more.

## Install

1. Download **`Auoris-Setup.exe`** from the [latest release](../../releases/latest).
2. Run it. Setup installs everything Auoris needs (Ollama, and optionally the AI model).
3. Windows may show "Windows protected your PC" because the installer isn't code-signed. Click **More info, then Run anyway**.

Installed copies update themselves automatically when a new release is published here.

## Features

- 💬 **Chat** and ⌘ **Code** modes, with saved history, incognito chats and slash commands
- 🎙 **Voice-to-text** dictation in every chat and message box
- 🧭 **Explore**: find and download GGUF models from Hugging Face, with GPU-fit estimates
- ⏱ **Routines**: prompts that run on a schedule
- 🔒 Permission modes, including an "AI decides" mode with built-in safety rules
- 💬 **Messages**: Servers with channels, roles and banners, DMs and group chats, with emoji reactions, replies and forwarding
- 🤝 **AI Projects**: shared AI projects with friends, without exposing anyone's API keys
- 🖥 **Hosting**: game server hosting for Minecraft, Valheim, Rust and more (Auoris Plus)
- 🎮 Rich presence: see what friends are playing, with a link to join
- ⛏ A Minecraft launcher with Microsoft sign-in, Fabric and the Auoris Client, with capes, hats, pets and tool skins
- 📱 A companion **phone app**, installable as a PWA, plus a local-only mode for chatting from your phone
- 🎨 Profiles with custom avatars, banners and effects, 9 languages, accent colors and a Modern or Legacy design
- 📊 Token usage and GPU memory stats

## Command line

Setup can add an `auoris` command to your PATH, so you can run `auoris chat` or `auoris --help` from any terminal.
